# Карты для приложения ТАЙГА

Векторные карты в формате Mapsforge (.map) для офлайн-работы приложения ТАЙГА:
проходимость, подписи, расчёт маршрутов, зона досягаемости.

Файлы карт лежат в разделе **Releases** этого репозитория, а список
доступных карт — в файле `maps.json` в корне. Приложение читает `maps.json`
по адресу «сырого» файла:

```
https://raw.githubusercontent.com/dmel83/taiga-maps/main/maps.json
```

## Что где

| Файл | Что это | Размер |
|---|---|---|
| `maps.json` | список карт, который читает приложение | меньше килобайта |
| `LENOBL.map` (в Releases) | Ленинградская область целиком | 183 983 843 байта |

Проверка целостности `LENOBL.map` (SHA-256):

```
096a11c160d05f75b11f6929c3c23b52fba1579f1f3253539b7461fdaf4870bd
```

## Как добавить новую карту

1. Загрузить файл `.map` в существующий или новый Release.
2. Скопировать прямую ссылку на файл (правая кнопка → «Копировать адрес ссылки»).
3. Дописать запись в `maps.json`: `title`, `file`, `url`, `bytes`, `updated`.

Порядок записей в `maps.json` — это порядок в списке на экране приложения.

## Происхождение данных и лицензия

Карты собраны из данных OpenStreetMap.

**© участники OpenStreetMap.** Данные распространяются по лицензии
[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

Файлы `.map` в этом репозитории являются производной базой данных (Derivative
Database) по смыслу ODbL. Это означает:

- при их распространении обязательно указание авторства и лицензии — оно
  приведено выше и продублировано на экране «Лицензии» в приложении;
- сами файлы карт распространяются на условиях ODbL 1.0, то есть их можно
  свободно использовать, в том числе в коммерческих целях, при сохранении
  этих же условий;
- лицензия ODbL распространяется на данные карты и **не** распространяется
  на исходный код приложения ТАЙГА — он лежит в отдельном репозитории
  и на других условиях.

Собрано инструментом [mapsforge map-writer 0.25.0](https://github.com/mapsforge/mapsforge).
